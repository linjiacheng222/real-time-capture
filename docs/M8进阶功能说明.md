## 一、渲染黑白名单（T8.3）

- 配置：`render_blacklist_file` / `render_whitelist_file`（默认 `config/captureapi/*.txt`）、`log_render_filter`；
- 格式：每行一个注册名；`#` 开头条目作为标签保留（首版不解析标签成员）；空行/注释忽略；
- 语义：白名单非空→仅白名单内允许；黑名单在白名单内挖洞（白减交）；双空=全部允许；
- 实现：`RenderFilterRegistry`（文件自动创建模板、热重载、HashSet 查询、命中计数）；WS `renderfilter.list/reload`；
- **未接入离屏场景收集阶段**（I8.3.2 需选中 LevelRenderer 收集钩子，W-095）；当前查询 API 可用但不影响实际画面。

## 二、音频黑白名单（T8.4）

- 配置：`audio_blacklist_file` / `audio_whitelist_file`；
- 实现：`AudioFilterRegistry`（模板/热重载/查询/计数）；WS `audiofilter.list/reload`；
- 语义同白减交；设计意图是“只影响环回捕获、玩家照常听到”；
- **未接入 SoundEngine 播放入口**（I8.4.1 Mixin 未实现）；服务端声音触发/删除（I8.4.2）需要 M9 组件，当前未提供。

## 三、多相机上限（T8.5）

- 配置：`max_cameras`（默认 1，范围 1–8，附录 B）；
- `CameraManager.create` 超限抛 `E_CAMERA_LIMIT`，WS 返回 `E_RATE_LIMIT`；`config.set max_cameras` 可运行时调整（实测 1→2 后第二路可创建）；
- 删除一路 active=0、相机列表正确回收；单路默认语义不变；
- **未实现“每路独立 FBO/PBO/编码器”**（架构要求复制单路全链）；当前多相机仅对象共存、单路 active 渲染；`{id}` 路由仍默认 0/active，多路分流未启用。

## 四、dev 运行时证据（2026-11-01）

```
renderfilter.list -> black=0, white=0
audiofilter.list  -> black=0, white=0
camera.create #1  -> ok
camera.create #2  -> E_RATE_LIMIT: max_cameras=1
config.set max_cameras=2 -> ok
camera.create #3  -> ok（id=2）
camera.list -> 两路共存，active=1
delete 1/2 -> active=0，列表回收
```
四个名单模板文件自动创建于 `run/config/captureapi/`。

- 多路**独立渲染链/资源随路回收**未实现；{id} 协议分流未启用；
- 名单标签成员解析、热更新性能、单路回归、主画面零扰动视频未测；
- 自绘叠加资产未附（T8.2 遗留）；
- 服务端声音触发/删除依赖 M9（下一轮）。
