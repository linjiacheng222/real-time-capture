## 一、S0 前置修复（已完成，与计划原文有出入）

计划 S0 写「流式 `renderOffscreen()` 缺少 `CameraSyncHook.onBeforeOffscreenRender(pose)`」。实际核查：

- **流式路径**早已有 before/after 调用（M3/T3.3 已接）；
- **实时调取（one-shot）路径**只缺 before，已补；
- 真正的阻断原因更深：`GameRenderer#renderLevel` 内部会调用 `Camera#setup(...)` 用玩家实体位姿**覆盖**渲染前写入的自定义机位。已新增：
  - `OffscreenPoseContext`（线程局部离屏机位栈）；
  - `CameraPoseMixin`（`Camera#setup` TAIL 重新应用离屏机位，仅上下文有效时）；
  - `CameraStateSnapshot.applyPoseOnly(...)` 共用；
  - 流式/实时调取均 push/pop 上下文。
- 另发现：客户端世界加载后处于**暂停菜单**时取帧会冻结；新增测试辅助 WS `client.unpause`（关闭暂停界面 + 关闭失焦自动暂停）；**该指令为测试辅助，发布前应移除或加门控**。
