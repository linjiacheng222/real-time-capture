## 二、S1 世界内出图（Spike B 已定位并修复；S1.1/S1.2 通过）

### 根因（关键）

`LevelRenderer.renderLevel` 在 item-entity 分支会临时绑定**主 framebuffer**，之后离屏流程直接 `glReadPixels`，**回读源不是离屏 FBO**，导致：
- 捕获帧近似玩家主视角（相机位置/朝向“不生效”）；
- 窗口/主 target 与 FBO 尺寸不一致时出现垂直条纹/花屏；
- 即使 FBO 内渲染正确，对外仍是错误画面。

### 修复

- **回读前重新绑定离屏 FBO**（流式 + 实时调取两条路径均加 `fbo.bind()`）；
- 保留 Camera.setup 位姿覆盖；
- 恢复异步双 PBO 回读（诊断期曾临时改为 immediate，验证后已恢复）；
- 清理 GUI-post 试验触发（无收益，恢复 AFTER_LEVEL）。

## 十二、S2.4 监听器翻转失败（2026-11-01 21:24，设计缺口）

- 测试：相机 yaw0→yaw180，+X 声源左右声道应翻转；脚本 `s2-listener-flip-check.ps1`；
- 结果：yaw0-sound L=479.63/R=106.65（L高）；yaw180-sound L=482.32/R=296.58（仍L高）→ **未翻转，S2.4 未通过**；
- 根因判断：`AudioListenerSync` 的 before/after 包住渲染线程 renderLevel，而音频采集线程 `alcRenderSamplesSOFT` 在窗口外执行，绝大多数拍使用玩家 Listener；

- 证据：docs/evidence/S2/listener-flip/（README + PCM）；
- 下一步：先完成 S3 可自动部分，再设计 Listener 修复方案并以六方位客观数据复测。
