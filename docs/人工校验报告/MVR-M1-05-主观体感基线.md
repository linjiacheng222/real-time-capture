## 1. 目的与范围

记录 M1 空壳阶段（仅底座与自检、无实际视频/音频功能）的主观体感基线：主菜单/世界内帧率、画面正常性、声音正常性、加载时间。用于 M2/M3 落地后对比"是否引入可感知回归"。

## 2. 前置条件

- 环境：与 M1 自动验证相同（JDK17、Forge 47.4.23、Embeddium 0.3.31、ModernFix 5.27.89）；
- 配置：`run/config/captureapi-client.toml` 默认值（`log_* = false`、`clock_logging = false`、自检属性仅在 dev 启动时启用）；
- 建议关闭其他无关模组（保持与发布环境一致的三个模组）。

## 3. 操作步骤

1. 启动客户端到主菜单，按 F3 记录主菜单平均帧率约 10s；
2. 进入一个固定测试世界（记录种子/坐标/时间/天气，便于后续对比），站立不动 30s，按 F3 记录平均帧率与 1% Low（若 F3 显示）或截图；
3. 在该世界移动/转视角 30s，记录帧率与是否有卡顿/掉帧；
4. 听声音（环境音/UI 音），记录是否有异响、断音、延迟；
5. 观察画面：无闪烁、无纹理错乱、无异常遮罩；
6. 记录从启动到主菜单耗时（`latest.log` 时间差或人工计时）；
7. 保存截图/日志，填写 §4。

- 与未装本模组的同环境基线相比，帧率差异在主观不可感知范围（建议记录具体数值供 M2/M3 对比）；
