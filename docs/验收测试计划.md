## 三、T7.2 性能与资源验收（5 I）

| 指标 | 方法 | 判据（建议值，实测定稿） |
|---|---|---|
| 帧率 | 30s 内 WS 视频帧时间戳计数 | 实际 ≈ fps_max ±2（默认 30） |
| 编码预算 | `log_pipeline_timing=true` 取 `[SYNC]`/PipelineTimings 均值 | 渲染线程总占用 < 23ms/帧（30fps 的 70%） |
| 单帧轮询 | Python requests 连续 1000 次 | P95 < 100ms；`max_qps` 超限 429 |
| 资源 | 健康端点/资源管理器计数；进出世界 10 轮 | FBO/PBO 复用、计数归零 |
| 硬依赖共存 | Embeddium+ModernFix 开/关；光影开/关 | 主画面无异常、泄漏计数平稳 |
| GC/内存 | 30min 采样（`jcmd GC.heap_info`） | 无持续增长（M7 长跑加时） |
