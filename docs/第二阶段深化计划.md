**目的**：判定离屏渲染管线是否真正产出正确画面。这是整个项目最关键的一步验证。

| 步骤 | 操作 | 通过判据 | 证据 |

| S1.1 | 进入世界→WS 创建相机→`GET /camera/0/frame` | HTTP 200；JPEG 可解码；非全黑/花屏 | frame.jpg＋响应头含 X-Frame-Timestamp |
| S1.2 | 改变相机位置/朝向→再次取帧 | 画面内容随位置变化 | 两帧对比截图 |

| S1.4 | 反复进出世界 10 轮→再取帧 | 每次均出图；FBO 计数归零后重建正常 | 日志＋帧截图 |

**前置修复（S0）**：`OffscreenRenderPipeline.renderOffscreen()` 补上 `CameraSyncHook.onBeforeOffscreenRender(pose)` 调用（当前 TODO 标注，一行代码修复，影响音频 3D 方向性）。

## 三、P1 深化——功能补全

### P1.1 流式路径监听器同步修复

- **问题**：`renderOffscreen()` 缺少 `CameraSyncHook.onBeforeOffscreenRender(pose)` 调用
- **修复**：在 `ShaderCompatHooks.beginOffscreenPass(pose)` 之后、`gameRenderer.renderLevel(...)` 之前插入一行
- **验收**：流式输出期间六方位听辨方向正确（与 S2.4 联测）
- **关联 I**：I3.3.2（同帧修改协议）

### P1.2 音频截面实现（W-071）

- **目标**：`CaptureApi` 的 `grabAudioSection(position, duration)` 返回一拍 PCM＋时间戳
- **设计**：I4.7.3（D-AUDIO-1 已裁决语义）
- **实现路径**：临时修改监听器到虚拟位→等一拍→读取→恢复（复用 I3.3 机制）
- **验收**：调用后返回非空 PCM＋时间戳；调用期间玩家听觉无扰动

### P1.3 远程 MP 客户端申请（T2.7.3）

- **目标**：客户端通过 M9 通道发送区块申请
- **前置**：M9 服务端组件已就位（SimpleChannel/TicketManager/Permissions）
- **实现**：客户端注册 `SimpleChannel` 消息处理；`CaptureChunkPlanner` 输出区块集合→经通道发送→接收受理结果
- **验收**：远程 MP＋M9：相机置于视距外→区块加载→画面出现远处内容

### P1.4 录像音频轨

- **目标**：RecordingSession 增加音频编码（AAC/PCM → FFmpeg 第二输入流）
- **实现路径**：FFmpeg 支持双输入流（`-f image2pipe -i - -f s16le -ar 44100 -ac 2 -i -`）
- **前置**：音频截面（P1.2）提供录音 tap
- **验收**：录像 mp4 含音频轨且可播放

### P1.5 Oculus 光影适配（W-043/W-044）

- **当前**：ShaderCompatHooks 为 no-op 桩
- **实现**：反编译 Oculus 1.20.1 确认 shader 帧缓冲映射注册 API → begin/end 钩子内绑定/解绑
- **降级**：不可行时按 D-M2-2 上呈（输出无光影帧 or 提示用户）
- **验收**：光影开启时离屏画面含光影效果；关闭时与无光影一致

### P1.6 Embeddium 四态共存实测

- **四态**：裸 Forge / 仅 Embeddium / 仅 Oculus / Embeddium+Oculus
- **方法**：`docs/验收测试计划.md` §三"硬依赖共存"
- **验收**：四态全不崩溃；目标环境（④）主画面无异常

### P1.7 参数治理收口

- 全量魔法数字扫描（T6.2.4 遗留）
- Configured 游戏内调整兼容实测
- 持久化回滚/原子性验证
- 损坏 TOML 启动行为验证
