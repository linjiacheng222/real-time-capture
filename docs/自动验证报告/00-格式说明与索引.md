# 自动验证报告 · 格式说明与索引

> 本目录收录「可由执行端自动跑出、可重复、带证据」的验证报告。原始证据仍在 `docs/evidence/` 与各验收记录中，本目录是**报告视图/交付物**；内容按统一格式整理，便于人工审阅。

## 一、统一报告格式（自动验证）

所有报告使用同一骨架（编号规则：`AVR-M1-xx`）：

1. 头部元信息：编号 / 类型 / 关联任务 / 生成日期 / 执行方 / 环境 / 结论 / 证据目录；
2. `## 1. 目的与范围`
3. `## 2. 前置条件与环境`
4. `## 3. 验证过程（步骤、命令、关键输出）` —— **详细描述过程，保证可复现、可读**
5. `## 4. 结果与证据`（表格：检查项 / 期望 / 实测 / 结论 / 证据路径）
6. `## 5. 判定标准与结论`
7. `## 6. 人工反馈区`（自动报告固定写「不适用」，并指向对应人工校验报告编号）
8. `## 7. 修复尝试记录（追加区）`（无失败项时写「无」；有则按时间追加，不覆盖历史）
9. `## 8. 附件与证据索引`

## 三、与人工校验报告的关系

- 自动报告覆盖「可机械化判定」的部分；无法由程序判定（真实进世界、听感、体感、`/mfrc` 交互等）的项目全部抽到 `docs/人工校验报告/`，两目录通过编号互相引用；
- 自动报告中的「人工反馈区」不填写，避免与人工报告重复。
