## 限制

- 普通立体声/无 HRTF 时，前/后/上/下无法仅靠左右声道能量区分；这是采集格式的物理限制，不代表实现错误。
- 若产品要求六方位全部可听辨，需要 HRTF（OpenAL Soft HRTF）或用户听感的主观判定；需用户裁决验收标准。
- 数据中部分方向受环境音/混响污染（up/down 能量高），结论以左右/翻转为主。
