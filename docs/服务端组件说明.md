# 可选服务端组件说明（M9）

> 状态：**服务端组件独立 jar 已可构建（源码级完成）**（2026-11-01）；客户端远程 MP 申请侧（T2.7.3）、专用服启动实测、兼容矩阵/协议窗口测试、发布配置仍未完成；按“测试后置”留测试分计划。
> 关联：M9 T9.1/T9.2/T9.3/T9.5、`docs/服务端组件双端契约-v0.1.md`、M2 T2.7.3。

## 一、产物与构建

- 构建：`gradlew build` 会额外生成 `build/libs/captureapi-0.5.0-server.jar`（独立 modid `captureapi_server`，经 ForgeGradle reobf，SRG 引用已核验）；
- 服务端 jar 不含客户端 Mixin/refmap（已排除并禁用 MixinGradle 注入，避免服务端启动引用缺失配置）；
- 安装：放入**服务端** `mods/` 目录；客户端无需安装组件（组件只补远程 MP 受理能力）。

## 二、已实现（服务端侧）

| 模块 | 实现 |
|---|---|
| T9.1 协议通道 | Forge `SimpleChannel`（channel `captureapi_server:main`）；四消息握手/区块申请/释放/通用响应；协议版本 1 |
| T9.2 ticket 生命周期 | 自定义 `TicketType`（类玩家 ENTITY_TICKING 级）+ `ServerLevel#getChunkSource().add/removeRegionTicket`；按玩家 UUID 追踪；释放/断线/停服回收 |
| T9.3 滥用防护 | 单包上限 2048、单玩家 4096、全局 16384、每秒 20 次申请（服务端配置可调）；错误码 E_RATE_LIMIT/E_PLAYER_LIMIT/E_GLOBAL_LIMIT/E_PACKET_LIMIT |
| T9.5 权限 | `default_permission`（默认 true）+ `permission_file`（UUID→boolean JSON）；服务端 OP 恒允许；无权限返回 E_NO_PERMISSION |
| 配置 | `config/captureapi_server-server.toml`（Forge SERVER 配置；含组件内部限额参数） |
| 版本 | 握手版本精确匹配 v1（版本窗口 N=2 尚未实现，见缺口） |

## 三、客户端侧现状（重要缺口）

- **T2.7.3 远程 MP 申请客户端侧未实现**：主模组没有注册该网络通道/发送握手与区块申请；因此即使服务端装组件，客户端也不会自动使用（保持自然加载降级）；
- 因此组件当前只能作为“服务端能力骨架”，无法端到端运行远程 MP 相机区块加载；
- 未装组件时客户端自然加载降级路径本身已存在（不发送申请），不会崩溃。

## 四、验证状态
