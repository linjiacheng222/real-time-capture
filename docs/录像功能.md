# 录像功能说明（T4.10）

> 状态：**I4.10.1 启停控制、I4.10.2 FFmpeg 视频管线代码完成**（2026-11-01）；**I4.10.3 音频轨未实现**（当前纯视频回退，明确提示）；完整录像文件/音画同步待测试分计划。
> 关联：I4.10.1~3、T4.9 recording_output_dir、M3 音频环、W-085/W-087/W-101/W-102。

## 一、控制入口（WS JSON）

| action | 参数 | 返回 result |
|---|---|---|
| `recording.start` | `cameraId`(0=active)、`fps`(默认 fps_max)、`jpegQuality`(默认 jpeg_quality)、`includeAudio`(bool)、`outputPath`(可选，相对/绝对) | `{running,frames,path,audioAvailable,error?}` |
| `recording.stop` | 无 | 同上（最终状态） |
| `recording.status` | 无 | 同上 |

- 单会话约束：已录制中再次 start → 错误；相机不存在/未激活 → 错误；FFmpeg 不可用 → 明确错误；
- 同一相机调整（adjust）在录像期间继续生效（运镜录制）；
- 网络服务关闭/游戏退出时自动 stop（避免 FFmpeg 残留进程）。

## 二、视频管线（I4.10.2）

- `ProcessBuilder` 启动：`ffmpeg -y -f image2pipe -framerate {fps} -i - -c:v libx264 -pix_fmt yuv420p -movflags +faststart output.mp4`；
- 录像线程 `captureapi-recording` 持续读 `VideoFrameBus` 最新帧（同帧时间戳去重），JPEG 写入 FFmpeg stdin；stdin 关闭→waitFor≤5s→强制销毁兜底；
- FFmpeg stderr 异步消费并保留末尾 20 行（崩溃/失败日志）；失败停止并保留已编码部分；
- 输出目录 `recording_output_dir`，文件名 `recording_<CaptureClock纳秒>.mp4`（避第二时间源，偏离计划的墙钟文件名）；
- `ffmpeg_path`、`recording_format=mp4` 新配置。

## 三、音频（I4.10.3，未实现）

- 计划：录像期间从 M3 环形缓冲订阅 AudioChunk→WAV→停止后二遍 FFmpeg 合流；
- **当前**：`includeAudio=true` 时记录 WARN 并回退纯视频，`audioAvailable=false`；假称音频轨不做；
- 实现障碍：`AudioRingBuffer` 当前单消费者（推流线程占用），录像需要第二消费者/录音 tap 或共享读取设计，待 M5 音频同步阶段统一设计；
- 因此“含音频 mp4/音画漂移≤50ms”验收项未完成。

## 五、已知缺口

- 音频轨/二遍合流、音画漂移未实现；
- 主菜单无世界帧，录制文件内容/时长/可播放性未验证；
- `jpegQuality` 参数目前未生效（帧由全局编码质量产出，录像无二次编码）；
- 相机删除自动 stop、权限门控、磁盘空间检查、FFmpeg 崩溃恢复用例未做；
- `fps` 只作为 FFmpeg 输入帧率声明，实际帧节奏由渲染产出决定（可变帧率风险待测）。
