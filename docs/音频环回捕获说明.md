# 音频环回捕获说明（T3.1）

> 状态：**T3.1 全链路代码完成（I3.1.1~I3.1.7）**；2026-10-31 dev 实测：环回设备/上下文创建成功、采集线程启动（`priority=9`、每拍 441 采样/1764B），无异常。
> 完整验收（1h 连续、切世界、听觉中继、延迟）归后续《测试分计划》；T3.2 环形缓冲为下一轮。
> 关联：M3 总述、I3.1.1~7、Spike A。

## 一、注入点（1.20.1 `Library`，非 Fabric 版 SoundEngine）

`AudioLibraryMixin` 四个注入：

| 注入 | 作用 |
|---|---|
| `@Redirect` `Library#openDeviceOrFallback` | 环回可用时返回 `alcLoopbackOpenDeviceSOFT` 设备；不可用走正常设备回退链 |
| `@Redirect` `ALC10#alcCreateContext`（remap=false） | 环回激活时注入格式属性（channels/type/frequency） |
| `@Inject` `Library#init` TAIL | 启动 `captureapi-audio-capture` 采集线程（MAX-1，daemon） |
| `@Inject` `Library#cleanup` HEAD | 停止线程、关扬声器线、句柄归零 |

> 注意：`@Redirect` 处理器按 Mixin 校验需为实例方法（首次静态写法导致 Mixin apply 失败，已修正）。

## 二、链路

1. **探测**：`ALC_SOFT_loopback` + `alcIsRenderFormatSupportedSOFT`（`sample_rate`/`channels`/16bit）+ Java Sound 中继线路预检；任一失败 → 正常设备 + 捕获禁用 + 明示日志（不静默）；
2. **格式锁定**：环回上下文创建时注入 `ALC_FORMAT_CHANNELS_SOFT`（MONO/STEREO）、`ALC_FORMAT_TYPE_SOFT=ALC_SHORT_SOFT`、`ALC_FREQUENCY=sample_rate`；
3. **采集线程**：`CaptureClock.nowNanos()` 节拍（期望时刻整数推算），每拍 `441` 采样/`1764` 字节（10ms）；超前 >1ms sleep，落后 >500ms 重同步；`alcRenderSamplesSOFT` 定长拉取；
4. **中继**：先（T3.2 接入后）写环形缓冲，再 `SourceDataLine.write` 到系统默认输出（8× 缓冲）；`poll_interval_ms`、`thread_priority` 可配；
5. **异常恢复**：主循环 catch Throwable 告警；渲染/中继错误计数、连续错误停止采集；退出设置上下文为空、关线。

## 五、配置

| 键 | 默认 | 说明 |
|---|---|---|
| `audio_enabled` | true | 总开关；false 走正常设备不采集 |
| `sample_rate` | 44100 | 环回上下文频率 |
| `bit_depth` | 16 | 环回类型（当前仅 16） |
| `channels` | 2 | 1=MONO，2=STEREO |
| `poll_interval_ms` | 10 | 每拍时长/采样数 |
| `thread_priority` | 9 | MAX-1，daemon |
