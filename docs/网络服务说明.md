# 网络服务说明（M4/T4.1）

> 状态：**T4.1 代码完成并通过 dev 运行时冒烟**（2026-10-31）：HTTP `/health` 200、WebSocket 握手+文本往返成功；token/LAN/连接上限/端口占用等异常路径待测试分计划。
> 关联：T4.1（I4.1.1~I4.1.6）、I4.1.3 默认参数、T4.2/T4.3 后续出口。

## 一、端口与绑定

| 服务 | 端口 | 说明 |
|---|---|---|
| HTTP | `net_port`（默认 25580） | JDK `HttpServer`；`/health` 免鉴权 |
| WebSocket | `net_port+1`（默认 25581） | 与服务同宿主；**端口推导为本项目决定**（Java-WebSocket/HTTP 不能共享监听端口；`/health` 的 `ws_port` 字段明示） |

- 默认仅 IPv4 回环 `127.0.0.1`（实测 JDK `getLoopbackAddress()` 在 Windows 返回 `::1`，已显式改为 IPv4）；
- `lan_enabled=true` 且 `bind_local_only=false` 时绑定 `0.0.0.0`，日志 WARN + 游戏内聊天栏提示；
- token 默认关；开启后 HTTP 校验 `X-CaptureAPI-Token`（或 query `token`），WS 校验握手 `?token=`；`/health` 始终免鉴权且不含 token。

## 二、生命周期与连接管理

- 启动：`FMLClientSetupEvent` → `NetworkServiceManager.start()`（幂等）；
- 关闭：JVM shutdown hook → 停 WS → 停 HTTP → executor 释放端口；
- 端口占用：捕获 `BindException`，日志提示改 `net_port`，游戏继续运行；
- WS 连接：注册表 + `max_connections`（默认 16，超限 503/拒绝）+ 元数据（来源/时间）；
- 健康端点 `GET /health` 返回：`running/http/ws/ws_port/bind/lan_enabled/connections/max_connections/rejected_connections/errors/uptime_ms/token_required`。

## 三、实现偏离记录（按“有问题先保留”）

计划（I4.1.1）选用 **Java-WebSocket**；dev 运行时 Forge 模组类加载器不暴露普通 Gradle `implementation` 依赖（`ClassNotFoundException: org.java_websocket.server.WebSocketServer`），jarJar/打包会引入额外构建风险。**实际改为纯 JDK 最小 RFC6455 服务端实现**（握手/SHA-1/文本/二进制/分片长度/掩码/关闭/并发上限），零第三方依赖、零 license 新增。能力满足 T4.1/T4.2/T4.3 所需；性能/极端帧/分片聚合未测，留在 T4.2 联调时验证。
