# 参数治理说明（M6）

> 状态：**M1~M6 全部 TOML 参数归并完成、默认值/范围按附录 B 收口、运行时改参（config.get/set）完成**（2026-11-01）；M8/M9 参数、Configured 兼容实测、持久化原子性/回滚、完整变更订阅待后续模块/测试分计划。
> 关联：I6.1.1~4、I6.2.1~4、I6.3.1~3、附录 B。

## 一、参数归并（T6.1）

- `CaptureConfig` 现有 35 个 TOML 键，覆盖附录 B 的 M1~M6 全部参数；
- 一致性脚本：`python scripts/verify-config-consistency.py` → 当前 **PASS**（附录 B 46 个 TOML 参数中仅 11 个 M8/M9 未实装参数允许缺失）；
- 默认值/范围按附录 B 修正：`max_connections=8`（1–64）、`max_qps`（1–240）、`warn_threshold_ms=50`（5–500）、新增 `persist_changes=false`；
- M8/M9 参数（滤镜/叠加/名单/max_cameras/权限）随对应模块实装登记，脚本允许清单已列明。

## 二、运行时改参（T6.3，已实现）

WS 指令：

```json
{"id":"1","action":"config.get","params":{"key":"fps_max"}}
{"id":"2","action":"config.set","params":{"key":"fps_max","value":15}}
```

- 即时类支持键：fps_max/jpeg_quality/encode_async/near_plane/far_plane/sound_range/chunk_rescan_ms/audio_enabled/poll_interval_ms/max_connections/max_qps/frame_cache_ttl_sec/sync_monitor_enabled/warn_threshold_ms/persist_changes/recording_output_dir/ffmpeg_path/log_* 等；
- **需重启类**（video_resolution/sample_rate/bit_depth/channels/thread_priority/ring_capacity_sec/net_port/bind_local_only/token_enabled/recording_format）运行时拒绝并返回明确提示（不静默）；
- 应用路径：spec 值写入 → `CaptureParams.refreshFromSpec(RELOAD)` 重建快照（毫秒级）；范围校验单点（更严者生效）；
- 优先级（T6.3.1）：运行时值=临时态立即生效；TOML=基线；重启回基线；`persist_changes=true` 时 `SPEC.save()` 尝试写回成为新基线（默认 false，探索性调整不污染配置）；
- 回滚/原子写回：**未实现**（单级回滚、临时文件原子替换待 T6.3.2）。
