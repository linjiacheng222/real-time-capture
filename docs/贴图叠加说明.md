# 贴图叠加说明（T8.2）

> 状态：**T8.2 叠加链路核心完成**（2026-11-01）：目录发现/PNG 加载/2D 参数模型/CPU 合成/WS 控制/固定顺序；世界内画面合成与性能未测。贴图资产必须用户自绘（版权红线）。
> 关联：T8.1 滤镜（顺序：滤镜→叠加→编码）、配置 `overlay_directory`/`overlay_enabled`。

## 一、目录与加载（I8.2.1）

- 目录：`config/captureapi/overlays`（`overlay_directory` 可配）；首次自动创建 README；
- PNG 一文件一叠加（文件名=叠加名，去掉 .png）；损坏/非 PNG 跳过 WARN；
- 加载为 CPU BufferedImage（当前实现；资源生命周期为全局，世界级 GPU 纹理登记待后续）；
- 热重载：WS `overlay.reload`。

## 二、2D 参数模型（I8.2.2）

`overlay.show` 参数：`image`（必填）、`x/y`（归一化中心 0~1，默认 0.5）、`scaleX/scaleY`（>0，默认 1）、`rotation`（度，绕中心）、`opacity`（0~1，默认 1）。多层按调用顺序合成（后调用在上）。

## 三、合成链路与顺序（I8.2.3/I8.2.4）

- 固定顺序：**滤镜 → 叠加 → JPEG 编码**（水印不被滤镜灰度化）；
- CPU 合成到捕获帧副本（alpha blend），主画面不参与；
- `overlay_enabled=false`（默认）时不生效；合成异常回退原帧，捕获流继续；
- 仅流式/实时调取编码前生效。

## 四、WS 控制

| action | 参数 | 说明 |
|---|---|---|
| `overlay.list` | — | 贴图/图层/开关状态 |
| `overlay.show` | image,x,y,scaleX,scaleY,rotation,opacity | 追加图层 |
| `overlay.clear` | — | 清空图层 |
| `overlay.reload` | — | 重扫贴图目录 |

`config.set overlay_enabled true` 可运行时开启。

## 五、dev 运行时证据（2026-11-01）

```
overlay.list -> images=["test_overlay"], enabled=false, layers=[]
overlay.show（x=0.5,y=0.5,scaleX=2,rotation=15,opacity=0.8）-> ok，layer 入列
overlay.show nope -> E_NOT_FOUND
overlay.clear -> layers=[]
```
（测试 PNG 为临时自绘测试图；尚未在真实世界帧上验证合成像素。）

## 六、已知缺口

- 世界内合成画面/多层层序/分辨率一致性/性能未测；
- 贴图未登记为世界级资源（CPU BufferedImage 当前全局；与 I8.2.1 的生命周期要求有偏差）；
- 叠加参数未持久化到 TOML（运行时图层列表内存态）；
- 自绘资产未提供（仅目录/README，用户自备；避免版权风险）；
- 与滤镜联合顺序仅代码固定，未做实际画面验证。
