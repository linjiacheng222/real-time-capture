# 视野形状系统说明（T4.8）

> 状态：**参数模型/校验/投影适配完成**（2026-11-01）；dev WS 运行时已验证球面锥缺参/越界拒绝、合法创建、rect↔cone 切换；弧形画面视觉确认与切换延迟/1000 次切换/光影滤镜组合归测试分计划。
> 关联：I4.8.1~4、T2.1.4 `ViewProjection` 扩展点、I4.3 控制指令、T2.6 光影。

## 一、参数模型（`ShapeModel`，随 CameraSpec 快照）

| 形状 | id | 参数 |
|---|---|---|
| 矩形（默认） | `rect` | 无额外参数；沿用相机 FOV + 离屏宽高比 |
| 球面锥 | `sphere_cone` | `angle`（开角，度，∈(0,180)）、`axisLength`（母线/轴长，>0，作为远裁剪）、`axisYaw/axisPitch`（独立轴方向；当前仅存参，轴默认随相机） |

- 参数随 `CameraSpec` 不可变快照流转（线程安全由不可变对象保证）；
- WS `camera.create/adjust` 可直接指定 `shape/angle/axisLength/axisYaw/axisPitch`；返回 JSON 同步带这些字段；
- 矩形/锥切换通过 `camera.adjust` 即时生效（投影矩阵每帧按快照计算）。

## 二、校验规则（I4.8.2，单点定义）

- `angle`：有限数且 **严格在 (0,180)**（0/180 均拒绝，边界语义保守）；
- `axisLength`：有限数且 **>0**；
- `axisYaw/axisPitch`：有限数，pitch ∈[-90,90]；
- 球面锥缺 `angle`/`axisLength` → `E_MISSING_PARAM`；越界/非法 → `E_PARAM_RANGE`，message 含字段与范围；
- 未知形状 id → `E_PARAM_RANGE`（支持 rect/sphere_cone）。

## 三、投影适配（I4.8.3）

`SphereConeProjection implements ViewProjection`：
- 锥角 → 透视 FOV（垂直）；`axisLength` → far；near 用配置 `near_plane`；宽高比用离屏分辨率；
- 按既定方案**不写自定义几何裁剪**，离屏渲染管线零改动；
- 标准透视的远平面为平面，“球面弧形底面”的视觉确认归 I4.8.4；若视觉不符预期 → 上呈，不在实现层自行解释。

## 五、已知缺口

- 世界内球面锥实际画面（弧形过渡/锥外裁剪）未视觉验证；
- 切换延迟（<1 帧）、首帧无残留、1000 次切换资源稳定、与光影/滤镜/出口组合矩阵未测；
- 独立轴方向参数仅存储、未参与矩阵（扩展位）；
- 相机指令 schema 文档需同步 shape 新字段（已在本文件记录，schema 文档 T4.3 待补章节）。
