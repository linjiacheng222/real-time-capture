## 1. S2.1 听觉中继 + S2.4 六方位听辨（约 3 分钟）

运行：
```powershell
powershell -ExecutionPolicy Bypass -File scripts\s2-sixdir-listen.ps1
```

脚本依次播放 **front → back → left → right → up → down**，每个 2.5 秒。请记录：

1. 六声实际听到的方向序列（可写“前/后/左/右/上/下/分不清”）；
2. S2.1：是否有 **静音、断续、异常回声、爆音**；
3. 是否接受“**相机激活时听到相机视角音频**”这一取舍（当前为保证方向性）。

回复模板：
```
S2.1 听感：正常 / 静音 / 断续 / 回声 / 爆音（具体）
S2.4 实际序列：front=?, back=?, left=?, right=?, up=?, down=?
取舍：接受 / 不接受（要求零扰动）
```

## 2. S5 ≥4h 长跑（挂机/正常游玩均可）

运行一条命令：
```powershell
powershell -ExecutionPolicy Bypass -File scripts\s5-user-long-run.ps1 -Hours 4
```
- 脚本会自动创建相机并在同一终端采样 4h；
- **保持终端打开**，可正常游玩/挂机；
- 结束后 CSV 在 `docs/evidence/S5/long-run/health-*.csv`。

回复模板：
```
长跑时长：4h
是否崩溃/卡死：否/是（描述）
体感：正常 / 卡顿 / 断流 / 其他
CSV 路径：docs/evidence/S5/long-run/health-xxxx.csv
```
