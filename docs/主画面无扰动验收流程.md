# 主画面无扰动验收流程（T2.3.3）

> 状态：流程已固化（2026-10-31）；执行归入后续《测试分计划》（用户指示：测试后置）。
> 复用：MS2 主画面零扰动验收、M7 T7.3 长跑（同一检查单，避免两套标准）。
> 关联：I2.3.1 状态保存/恢复、I2.3.2 相机临时替换、T2.6 光影态。

## 一、目的

验证启用了离屏渲染后，**主画面与未启用捕获的对照完全一致**（零扰动），且无 GL 错误增长。用于发现状态保存集遗漏（雾、天空、投影、相机字段等）。

## 二、前置条件

- 同一世界（固定种子/坐标/时间/天气/视角）与同一客户端配置（Embeddium/ModernFix 固定版本）；
- 对照组：`active` 相机不存在（离屏渲染不启用）；
- 实验组：存在 active 相机，`fps_max=30`，离屏渲染持续运行；
- 无光影态为 M2 底线；光影态（Oculus）为 P1，归 T2.6 联合执行；
- GL 错误以 `latest.log`/`debug.log` 中 `GL_INVALID_`、`GL error`、`crash-reports` 为准。

## 三、操作步骤（无光影态，两轮）

1. **基线截图**：未启用相机（对照组）下进入世界，固定视角/坐标/天气，按 F2 截取主画面，连续截 6 张（每 10s 一张），命名 `baseline-<序号>.png`；
2. **启用离屏**：创建/激活相机（离屏渲染开始，`fps_max=30`），玩家正常移动/转头 60s；
3. **实验截图**：在**相同坐标/视角/天气/时间**下暂停操作，按 F2 截 6 张（每 10s），命名 `capture-<序号>.png`；
4. 重复步骤 1~3 共 2 轮；
5. 关闭相机（对照组恢复），再截 2 张确认无残留异常；
6. 收集两轮全部截图 + `latest.log`/`debug.log` + 若有的 crash-report；
7. 对比：逐张目视 + 像素抽检（同坐标/视角/天气下差异率应为 0；HUD 隐藏 `F1` 可减少干扰）。

## 四、判定标准（与主说明 §六/MS2 对齐）

- [ ] 对照/实验同条件截图逐张一致（差异率 = 0；允许 HUD/时间等系统元素差异，需在记录中说明并统一 `F1` 隐藏 HUD）；
- [ ] 60s 内无主画面闪烁/模型错位/光影崩坏/视角跳变；
- [ ] 关闭相机后无"残留视角/相机未恢复"现象；
- [ ] GL 错误计数零增长（`GL_INVALID_*`/`GL error` 0 条；无新增 crash-report）；
- [ ] 两轮结果一致；
- [ ] 若触发不符：按状态保存集逐项排查（FBO/viewport/clear/纹理/program/projection/fog/camera），修复后重跑本流程，并在 T2.3 验收记录追加。
