## 红线 2 详细核验（T1.1.5）

**核验方法**：
1. 生成并保存 `gradlew dependencies --configuration runtimeClasspath` 快照；
2. 对快照做关键词扫描：`connector`、`fabric-loader`、`quilt`、`fabric.mod`、`quilted`（大小写不敏感），要求 **0 命中**；
3. 解包产物 jar，列出全部条目，检查无 `fabric.mod.json` / `quilt.mod.json`；
4. 核对构建配置：`mappings channel: 'official'`（Mojmap）、依赖树无混合加载器；`mods.toml` 为 `javafml` 主加载器。

**证据**：
- `docs/evidence/T1.1/deps-runtimeClasspath.txt`：304 行，关键词 0 命中；
- `docs/evidence/T1.1/jar-entries.txt`：21 项，Fabric/Quilt 元数据 0；
- `docs/evidence/T1.1/jar-MANIFEST.MF`、`captureapi.mixins.json`、`captureapi.refmap.json`；
- `scripts/build.ps1` 自动校验：`产物 jar 无 Fabric/Quilt 元数据（红线 2）` PASS。

**结论**：红线 2 在 T1.1 范围内**通过**；后续新增依赖/构建配置时按同一方法复验（并入 `verify-env.ps1`/`build.ps1` 持续守护）。
