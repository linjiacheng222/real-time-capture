## 红线 5 详细核验（T1.6，实物部分）

**核验方法**：直接读取参考 jar/源码仓库的 LICENSE/元数据（不以网页/记忆为准），逐项比对版权行；将协议分类（MIT/MPL/GPL）与复用义务写入 NOTICES 与标注规范。

**证据与结论**：
- DebugBridge：仓库 LICENSE = MIT（`Copyright (c) 2026 Weikeng Chen`），与工程 `MIT-DebugBridge.txt` 逐字一致；
- Record-able：jar `LICENSE_record-able` = MIT（`Record-able contributors`）；上游仓库 LICENSE = MIT（`Minewind's Jo Eusebe`）——两版本均留档（`MIT-Record-able.txt` / `MIT-Record-able-repo.txt`）；
- Pixelshot：jar `mods.toml` license=**MPL-2.0**、authors 含 BarracudaATA/Fuzs/Pascal Roeleven（fork 署名完整）；上游 Mineshot 归属在 description 中声明；
- Mineshot Revived：仓库 LICENSE=**GPL-3.0**，仅设计参考，**禁复制**；
- PuzzlesLib：代码 MPL-2.0、资产 ARR，不依赖不移植。

**结论**：红线 5 在 M1 范围内**通过**（声明与规范落地、实物核验完成）；代码复制场景的标注义务自 M2 起由首个移植 PR 抽检（100%）。

## 红线 4 详细核验（T1.4，自动部分）

**核验方法**：
1. 静态扫描（`build.ps1`「红线 4：时钟纪律静态扫描」）：遍历 `src/main/java` 全部 `.java`，禁止 `System.currentTimeMillis()` / `Instant.now()` / `System.nanoTime()` / `getGameTime()`；唯一白名单为 `core/time/CaptureClock.java`（nanoTime 唯一入口）与 `core/time/LogTimeConverter.java`（日志墙上时钟）；
2. 单调性自检：`CaptureClock.selfTestMonotonic(1000)` 连续采样非递减；
3. 运行抽样：`clock_logging=true` 时 `ClockTickLogger` 每秒输出 `时钟自测`（nowNanos + 间隔），实测间隔约 1037/1042ms。

**证据**：
- `build.ps1` 校验项 PASS（24/24；白名单外 0 命中）；
- `docs/evidence/T1.4-T1.5/config-correction-latest.log`：`时钟自测` 行；
- `docs/T1.4-T1.5-验收记录.md` §2/§3/§8。

**结论**：红线 4 在 M1 范围内**通过**；M2/M3 打标语义由 M5 冻结取点后复验。
