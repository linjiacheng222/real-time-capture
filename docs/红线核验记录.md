## 红线 3 详细核验（T1.2/T1.3，自动部分）

**核验方法**：
1. GL 线程守卫自检：渲染线程调用应通过；独立线程调用应产生违规日志（开发期可选断言）；由 `CoreSelfTest`（`captureapi.debug.selftest=true`）执行并输出 `核心自检 PASS`；
2. 资源管理器生命周期自检：独立管理器实例注册 2 个世界资源 → `onWorldJoin` 创建 → 校验计数/`get()` → `onWorldLeave` 销毁 → 校验归零 → 重复 `onWorldLeave` 幂等 → 销毁后 `get()` 抛 `IllegalStateException`；
3. 构建/环境脚本持续守护：`verify-env.ps1` 检查 `核心自检 PASS` 日志与 `资源管理器自检 PASS` 日志；
4. 世界内真实进出/10 轮压测为人工项（MS1 收尾，清单见 `docs/T1.2-T1.3-验收记录.md` §8）。

**证据**：
- `docs/evidence/T1.2-T1.3/run-client-key-lines.txt`：`核心自检 PASS（renderThread=true，channel 1000 次发布/读取=true，资源管理器=true）`、`资源管理器自检 PASS`、GL 线程违规负例（预期）、资源创建/销毁/统计行；
- `docs/evidence/T1.2-T1.3/verify-env-final.md`：38 PASS/0 FAIL/0 WARN（含「M1 核心自检日志」检查 PASS）；
- `docs/T1.2-T1.3-验收记录.md`：逐 I 验收与人工项清单。

**结论**：红线 3 在自动可验证范围内**通过**；世界内真实生命周期与 10 轮压测待 MS1 收尾补证。

## 红线 2 详细核验（T1.1.5）

**核验方法**：
1. 生成并保存 `gradlew dependencies --configuration runtimeClasspath` 快照；
2. 对快照做关键词扫描：`connector`、`fabric-loader`、`quilt`、`fabric.mod`、`quilted`（大小写不敏感），要求 **0 命中**；
3. 解包产物 jar，列出全部条目，检查无 `fabric.mod.json` / `quilt.mod.json`；
4. 核对构建配置：`mappings channel: 'official'`（Mojmap）、依赖树无混合加载器；`mods.toml` 为 `javafml` 主加载器。

**证据**：
- `docs/evidence/T1.1/deps-runtimeClasspath.txt`：304 行，关键词 0 命中；
- `docs/evidence/T1.1/jar-entries.txt`：21 项，Fabric/Quilt 元数据 0；
- `docs/evidence/T1.1/jar-MANIFEST.MF`、`captureapi.mixins.json`、`captureapi.refmap.json`；
- `scripts/build.ps1` 自动校验：`产物 jar 无 Fabric/Quilt 元数据（红线 2）` PASS。

**结论**：红线 2 在 T1.1 范围内**通过**；后续新增依赖/构建配置时按同一方法复验（并入 `verify-env.ps1`/`build.ps1` 持续守护）。
