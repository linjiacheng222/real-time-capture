## 红线 4 详细核验（T1.4，自动部分）

**核验方法**：
1. 静态扫描（`build.ps1`「红线 4：时钟纪律静态扫描」）：遍历 `src/main/java` 全部 `.java`，禁止 `System.currentTimeMillis()` / `Instant.now()` / `System.nanoTime()` / `getGameTime()`；唯一白名单为 `core/time/CaptureClock.java`（nanoTime 唯一入口）与 `core/time/LogTimeConverter.java`（日志墙上时钟）；
2. 单调性自检：`CaptureClock.selfTestMonotonic(1000)` 连续采样非递减；
3. 运行抽样：`clock_logging=true` 时 `ClockTickLogger` 每秒输出 `时钟自测`（nowNanos + 间隔），实测间隔约 1037/1042ms。

**证据**：
- `build.ps1` 校验项 PASS（24/24；白名单外 0 命中）；
- `docs/evidence/T1.4-T1.5/config-correction-latest.log`：`时钟自测` 行；
- `docs/T1.4-T1.5-验收记录.md` §2/§3/§8。

**结论**：红线 4 在 M1 范围内**通过**；M2/M3 打标语义由 M5 冻结取点后复验。

2. 对快照做关键词扫描：`connector`、`fabric-loader`、`quilt`、`fabric.mod`、`quilted`（大小写不敏感），要求 **0 命中**；
