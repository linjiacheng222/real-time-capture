## 四、S6 放行裁决

**条件放行（代码侧）**：S1/S3 自动 E2E/S4 稳态/S5 短测/S6 红线代码证据齐备；P1.1~P1.4 已实现，P1.3/P2.5 dev 专用服验证。

4. P2.5 生产专用服 **主链路已 PASS**；剩余 Permissions/多玩家/全局限额矩阵；
5. 发布前清理/门控测试专用 WS 指令（`client.*`、`audio.section`、`shader.status` 等）；
6. GitHub 推送裁决。
