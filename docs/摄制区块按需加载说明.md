# 摄制区块按需加载说明（T2.7）

> 状态：**I2.7.1 代码实现完成**；I2.7.2 单机 ticket / I2.7.3 远程 MP / I2.7.4 ModernFix 冒烟待后续 Spike/测试分计划（用户指示测试后置）。
> 关联：T2.1.2 相机矩阵、T2.9 服务端组件契约、附录 B `sound_range`/`chunk_rescan_ms`。

## 一、区块集合求取（I2.7.1，已实现）

`com.captureapi.video.chunk.CaptureChunkPlanner`：

1. **画面集合**：`projection × view` 构造 `FrustumIntersection`，对相机周围区块 AABB（`y=minBuildHeight..maxBuildHeight`）做视锥求交；候选扫描半径 `ceil(far_plane/16)+1`，上限 64 区块（极端 far 的安全阀）；
2. **声音集合**：以相机所在区块为中心、`sound_range`（格）折算的圆形水平半径；
3. **集合 = 画面 ∪ 声音**（非矩形范围框；视锥决定形状，声音半径只补充近场）；
4. **节流重算**：相机移动 ≥4 格 / 转向 ≥5° / FOV 变化 ≥1° / far 或 sound_range 变化 / `chunk_rescan_ms` 到期才重算；
5. 渲染管线在流式离屏帧的位姿解析后调用 `CaptureChunkPlanner.get().update(pose)`；结果为不可变 `CaptureChunkSet`（chunk long 集合）。

## 六、风险

- 当前无 ticket 申请：相机超出玩家视距时画面仍缺区块（功能在 I2.7.2/I2.7.3 补齐）。
