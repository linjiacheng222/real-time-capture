# CaptureAPI 临时测试指令表（游戏内聊天命令）

> 所有指令以 `/` 开头，在游戏聊天框输入并回车。
> **落盘目录：`E:\捕获接口\testcases\commands`**（命令自动创建）。
> 本指令集为临时测试工具，发布前应移除/门控。
> **/get_image** 是快捷入口：玩家脚部 Y+10 的位置、pitch=90° 俯视，导出 PNG（无音频）。

## 一、根命令 / 帮助

| 指令 | 作用 | 示例 |
|---|---|---|
| `/captureapi` | 显示帮助 | `/captureapi` |
| `/captureapi help` | 显示帮助 | `/captureapi help` |
| `/captureapi status` | 相机/录像/音频/滤镜/叠加/远程/光影总状态 | `/captureapi status` |
| `/captureapi network` | 显示 HTTP/MJPEG/WS 地址 | `/captureapi network` |
| `/captureapi unimplemented` | 列出未实现/暂缓功能 | `/captureapi unimplemented` |

## 二、相机

| 指令 | 作用 | 示例 |
|---|---|---|
| `/captureapi camera create <x> <y> <z> <yaw> <pitch> [fov]` | 创建并激活相机；yaw/pitch 单位度，pitch 正=向下 | `/captureapi camera create 100 80 200 0 45` |
| `/captureapi camera top [height]` | 玩家位置上方 height 格（默认 10）俯视 90° 创建相机 | `/captureapi camera top` |
| `/captureapi camera adjust <id> <x> <y> <z> <yaw> <pitch> [fov]` | 整体替换相机参数 | `/captureapi camera adjust 1 120 75 210 90 30` |
| `/captureapi camera activate <id>` | 激活指定相机 | `/captureapi camera activate 1` |
| `/captureapi camera pause <id>` | 暂停相机 | `/captureapi camera pause 1` |
| `/captureapi camera resume <id>` | 恢复相机 | `/captureapi camera resume 1` |
| `/captureapi camera delete <id>` | 删除相机 | `/captureapi camera delete 1` |
| `/captureapi camera list` | 列出相机 | `/captureapi camera list` |
| `/captureapi camera status` | 当前 active 相机 | `/captureapi camera status` |
| `/captureapi camera clear` | 清空全部相机 | `/captureapi camera clear` |

## 三、单帧截图（无音频）

| 指令 | 作用 |
|---|---|
| `/get_image` | **快捷：玩家 Y+10 俯视 PNG** |
| `/captureapi frame` | 等同 frame top PNG |
| `/captureapi frame top [png\|jpeg]` | 玩家 Y+10 俯视，默认 PNG |
| `/captureapi frame current [png\|jpeg]` | 用 active 相机当前参数截图；无相机则失败 |
| `/captureapi capture` | 等同 frame current PNG |

输出路径：`E:\捕获接口\testcases\commands\capture-<kind>-<CaptureClock纳秒>.png/jpg`。

## 四、录像（视频导出）

| 指令 | 作用 |
|---|---|
| `/captureapi record start` | 30fps、无音频，录制 active 相机 |
| `/captureapi record start <fps>` | 指定 fps（1–60），无音频 |
| `/captureapi record start <fps> audio` | 指定 fps + 音频轨（需 FFmpeg） |
| `/captureapi record start audio` | 30fps + 音频 |
| `/captureapi record start <fps> silent` | 显式无音频 |
| `/captureapi record stop` | 停止并落盘 |
| `/captureapi record status` | 查看录制状态/路径 |

输出路径：`E:\捕获接口\testcases\commands\recording-<CaptureClock纳秒>.mp4`。
**需要 active 相机；FFmpeg 必须在 PATH（或 config `ffmpeg_path`）。**

## 五、音频

| 指令 | 作用 |
|---|---|
| `/captureapi audio status` | 环回状态/写入/丢弃/静音计数 |
| `/captureapi audio section [chunks]` | 音频截面（默认 3 拍，1–100）；输出 samples/bytes/时间戳 |

## 六、参数（运行时配置）

| 指令 | 作用 | 示例 |
|---|---|---|
| `/captureapi config list` | 列出当前参数（最多 40 项） | `/captureapi config list` |
| `/captureapi config get <key>` | 读取参数 | `/captureapi config get fps_max` |
| `/captureapi config set <key> <value>` | 运行时改参（受范围校验；persist 按配置） | `/captureapi config set fps_max 15` |

## 七、滤镜 / 叠加

| 指令                                                           | 作用                                 |
| ------------------------------------------------------------ | ---------------------------------- |
| `/captureapi filter list`                                    | 已加载 JSON 滤镜/当前选择/统计                |
| `/captureapi filter select <name>`                           | 选择滤镜                               |
| `/captureapi filter reload`                                  | 重载滤镜目录                             |
| `/captureapi overlay list`                                   | 叠加贴图列表/是否激活                        |
| `/captureapi overlay show <image> <x> <y> <scale> [opacity]` | 显示叠加层（x/y 0–1，scale>0，opacity 0–1） |
| `/captureapi overlay clear`                                  | 清空叠加层                              |

## 八、名单 / 诊断

| 指令 | 作用 |
|---|---|
| `/captureapi list render` | 渲染名单解析摘要 + blockedQueries |
| `/captureapi list audio` | 音频名单解析摘要 + blockedQueries |
| `/captureapi list reload` | 重载两队名单（W-095 实际挂接未实现） |
| `/captureapi status shader` | 光影探测状态（Oculus/W-043 未实装） |
| `/captureapi status remote` | 远程 M9 申请状态（ready/requests/accepted/lastCode） |

## 九、未实现/暂缓（输入后直接输出说明）

| 指令 | 输出 |
|---|---|
| `/captureapi glsl` | GLSL 滤镜未做（P2.1 裁剪条件） |
| `/captureapi renderlist` | 渲染名单实际挂接未实现（W-095） |
| `/captureapi audiolist` | 音频名单实际挂接未实现（W-095） |
| `/captureapi multicam` | 多路独立渲染未实现（P2.3） |
| `/captureapi overlaygpu` | GPU 叠加未实现（P2.4） |
| `/captureapi oculus` | Oculus 离屏适配未实装（W-043） |

## 十、测试注意

1. 测试指令为**临时**，发布前移除；不影响 WS/正常 API；
2. `/get_image`、`frame` 为异步截图，聊天栏会先提示“开始截图”，完成后提示路径/字节；
3. PCL 实例需重启以加载最新 jar；
4. 若画面全黑/主画面，记录相机 id/位置/朝向与 `/captureapi status` 输出；
5. 录像音轨需要 FFmpeg；无 FFmpeg 会启动失败并提示；
6. 截图/录像文件都在 `E:\捕获接口\testcases\commands`，可整目录打包反馈。
