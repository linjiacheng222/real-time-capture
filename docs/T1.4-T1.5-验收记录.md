## 9. 重要集成发现（W 表建议新增）

**ModernFix 拦截 Forge 配置自动重载**：ModernFix 的 `org.embeddedt.modernfix.forge.config.NightConfigFixer` 会替换 NightConfig 的 `FileWatcher` 监控表，
把变更收集到 `configsToReload` 并通过提示要求用户执行 `/mfrc` 重载；Forge 原生 `ConfigWatcher` 不再自动触发。
证据：`config-correction-debug.log` 中 `Watching TOML config file … for changes` 存在但修改后无 `Config file … changed, sending notifies`；
`reload-test-latest.log` 中 ModernFix 提示 `/mfrc`。**影响**：参数热重载的用户路径在 modernfix 存在的环境中需通过 `/mfrc`（或 M4 网络侧自行调用重载联动），
M6 参数生效时机文档需纳入此事实；已建议登记 W-103。
